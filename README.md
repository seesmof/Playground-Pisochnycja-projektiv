# Генерація тексту (NLP)

Streamlit-застосунок для генерації тексту на основі локальної відкритої LLM (Qwen/Qwen2.5-1.5B-Instruct).

## Запуск

1. Встановіть залежності:
   ```bash
   uv sync
   ```
2. (Необов'язково) Увійдіть у Hugging Face для вищих лімітів:
   ```bash
   uv run hf auth login
   ```
3. Запустіть застосунок:
   ```bash
   uv run streamlit run app.py
   ```

Модель завантажується при першому запуску та кешується локально.
