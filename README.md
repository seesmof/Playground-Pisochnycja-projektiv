# Біблія — Читач

Простий офлайн-застосунок для читання `Bible.txt` (український переклад, UTF-8, формат рядків `КОД РОЗДІЛ:ВІРШ текст`, напр. `GEN 1:1 У початку…`).

Файли:
- `index.html` — розмітка
- `styles.css` — світла/темна тема
- `app.js` — парсер + навігація + пошук
- `Bible.txt` — 66 книг, 31 082 вірші

## Запуск

Браузери блокують `fetch("Bible.txt")` при відкритті через `file://`, тому запустіть локальний сервер:

```sh
python -m http.server 8000
```

потім відкрийте http://localhost:8000/

Або відкрийте `index.html` напряму і виберіть `Bible.txt` вручну через поле вибору файлу.

## Можливості

- Список книг (Старий / Новий Завіт), сітка розділів
- Читання розділів, копіювання вірша кліком по віршу (зі сповіщенням «Скопійовано»)
- Навігація ← / → (кнопки і стрілки клавіатури), гортання між книгами
- Пошук по всьому тексту (`/` для фокусу), з підсвічуванням; розуміє посилання типу `Буття 1:1`, `Пс 23`, `GEN 1:1`
- Випадковий вірш (🎲), розмір шрифту (A±), темна тема, запамʼятовування місця (`localStorage`, хеш `#GEN.1`)
